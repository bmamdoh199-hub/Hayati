موقع تطبيق حياتي

طريقة الاستخدام:
1) افتح index.html لمعاينة الموقع.
2) لتمكين زر تحميل التطبيق، ضع ملف APK النهائي داخل مجلد downloads وسمّه بالضبط: hayati.apk
3) ارفع محتويات هذا المجلد إلى GitHub Pages أو أي استضافة مواقع ثابتة.
4) بعد نشر التطبيق على Google Play، يمكن استبدال زر «قريبًا على Google Play» برابط صفحة التطبيق.

ملاحظات:
- لقطات الهاتف الحالية معاينات تصميمية توضيحية وليست صورًا فعلية من التطبيق.
- اسم المطور ورسالة الإهداء مكتوبان داخل index.html ويمكن تعديلهما بسهولة.
- الموقع لا يحتاج إلى تثبيت أو Backend.
